# CrumbLab Website

📌 Project Overview

CrumbLab is a modern, responsive laboratory website developed as a university **Web Application Development** project. The website provides users with an engaging interface to explore laboratory services, events, menus, and galleries while demonstrating full-stack web development concepts.

The project combines a responsive frontend with a Node.js and Express backend, showcasing practical experience in designing, developing, and deploying a complete web application.

🌐 **Live Demo:** https://mariyambashir.github.io/CrumbLab_website/

📂 **GitHub Repository:** https://github.com/MariyamBashir/CrumbLab_website
---

## ✨ Features

* 🏠 Responsive homepage
* 📋 Interactive menu page
* 🖼️ Image gallery
* 🎉 Events page
* 📱 Mobile-friendly design
* ⚡ Fast and responsive user interface
* 🔧 Node.js & Express backend
* 🗄️ MongoDB database integration
* 🌐 Deployed frontend using GitHub Pages
